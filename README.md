# Battle Base

ファンタジー世界を舞台にした、2人用リアルタイム対戦カードゲームです。ルームコードを共有すると、別々のブラウザから同じ対戦に参加できます。

## 起動

Node.js 20以降が必要です。

```sh
npm install
npm start
```

ブラウザで `http://localhost:3000` を開き、「新しいルームを作る」を選びます。表示された6文字のルームコードを相手に共有し、相手はそのコードを入力して参加します。ローカル対戦では、同じURLを2つのブラウザ/タブで開いてください。

## ルール

- 各プレイヤーの固定デッキは16枚。初期手札は4枚で、自分のターン開始時に1枚引きます。
- 英雄の生命力は20。相手の生命力を0にすると勝利です。
- ターンごとに使えるマナが1ずつ増え、最大10まで蓄積します。
- ユニットは召喚したターンには攻撃できません。次の自分のターンから、相手の英雄またはユニットを攻撃できます。
- 呪文には英雄を回復するもの、相手の英雄にダメージを与えるものがあります。
- 対戦中に接続が切れると、切断した側の敗北になります。

## 技術構成

Node.jsのHTTPサーバーが静的ファイルを配信し、WebSocketでルームと対戦状態を同期します。ルームと対戦データはメモリ上に保持されるため、サーバー再起動で消去されます。本番公開時はHTTPS/WSS対応のリバースプロキシと、永続化や不正接続への対策が別途必要です。
